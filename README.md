## 独立确认：3–5m

候选与阈值先冻结，再采集384个新配置、1536帧。相同双灯条支持总体，不通过模型拒识改变分母。下表是单帧识别结果，横向为光学相机XY误差范数。

| 模型 | 有效 / 应评 | 角点 P95 / px | 深度 P95 / cm | 横向 P95 / cm |
| --- | --- | --- | --- | --- |
| 深大原始模型（原生裁块） | 400/423 | 1.502 | 31.03 | 7.268 |
| 深大＋旧尺度校正 | 400/423 | 1.502 | 29.97 | 7.053 |
| 上一轮四点整板网络 | 419/423 | 0.389 | 9.30 | 2.036 |
| 新16点联合精定位 | 422/423 | 0.148 | 3.57 | 0.835 |

新模型的均值 / 中位数 / P95：角点 **0.085 / 0.078 / 0.148 px**，深度 **1.377 / 1.038 / 3.571 cm**，横向 **0.289 / 0.186 / 0.835 cm**。3–5m有效422/423，达到预定0.236px、7.43cm、1.06cm及812/817覆盖率参考。

全距离应评对象实际范围0.373–7.766m，有效1549/1567。八个距离桶中的三项P95和覆盖率都优于本次深大基线；1m内仍有213/228的覆盖短板，7–8m深度P95为11.26cm。不是每帧必识别，也不表示8m处和3–5m具有相同误差。

## 使用和限制

权重实际位于仓库的 weights/number3-glyph-v3/，包括粗检、精定位、大目标回退、原训练检查点及起始特征模型，没有LFS指针。使用 scripts/infer_glyph.py；输入内参及同曝光相机姿态，具体命令见[训练与推理](TRAINING_GLYPH.md)。examples/glyph-v3/提供原生示例、相机参数和实际推理输出。

最终四角是联合姿态重投影后的物理灯条端点，不能将0.148px写成原始四点头的误差。在线不读取目标真值、距离、朝向或未来状态。当前仅验证水平车体、固定装甲安装角、相机无roll、板中心高差±40cm的模拟器3号板；暗、正常、亮三种光照均保留。

**精度阶段通过，实时部署尚未通过。** 当前T4上未优化的PyTorch CUDA FP16参考实现整图中位252ms、P95 439ms，未达到10ms。TensorRT/INT8/NX、真实相机、真实运动模糊和其他编号未验收。识别结果不能直接当作未来预测精度或命中率。

旧版权重保留于 weights/number3-roll0-v2/，历史指标见[EVALUATION.md](EVALUATION.md)，旧版说明见[MODEL_CARD.md](MODEL_CARD.md)。原始图像与完整受保护资产保留在训练服务器；本次没有本地全量备份，也没有生成PDF报告。
